# 🔍 Multi-Threaded Port Scanner & Banner Grabber

A lightweight, high-performance CLI security tool written in Python. It allows network administrators and security enthusiasts to quickly identify open TCP ports on a target host and retrieve service banners.

## ✨ Features
- **Multi-Threaded Execution:** Powered by `ThreadPoolExecutor` for fast scanning.
- **Banner Grabbing:** Attempts to retrieve service identification strings from open ports.
- **Customizable Range:** Scan specific port ranges or default top 1024 ports.
- **Clean CLI Interface:** Colored output with structured status logging.
